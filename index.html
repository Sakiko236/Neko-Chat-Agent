设计哲学

“我们认为人类的指引在 Agent 工作流里是必须的。”

Neko Chat Agent 是一款做减法的 Agent。我们主动抛弃了 ReAct——不再让模型陷入冗长、不可控的多步自主循环与黑盒试错，但完整保留了对本地文件的直接修改权限。让 AI 专注于高效执行，而每一次方向判断都由你亲自掌控。

特性与使用

01

具备对本地文件的操作权限

支持直接读取、创建与修改本地文件。无需反复复制粘贴代码或文本，在你的明确指令下精准落盘修改。

02

支持多种格式文件上传

支持 PDF 文档、图片、代码源码及各类纯文本文件多选上传，自动识别类型并作为上下文融入当前对话。

03

双击猫猫头以新建会话

界面交互极度克制：单击窗口底部的猫耳光球展开输入框，直接双击猫猫头即可清空当前上下文并开启新会话。

04

首次使用需配置 API 端口

纯本地客户端架构，不绑定任何中心化云账号。首次启动后，请在设置中配置你的模型 API 端口与密钥即可开始使用。
